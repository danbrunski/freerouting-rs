# krt-grid-router

KiCadRoutingTools' grid router, vendored as its own crate so the MIT-licensed
code stays identifiable and upstream fixes can be re-vendored by diff.

- **Source:** https://github.com/drandyhaas/KiCadRoutingTools, `rust_router/`
  (crate `grid_router` 0.23.0), commit `0486e799144050d4e826f71bb31acdc7275af2a2`.
- **Licence:** MIT, Copyright (c) 2026 drandyhaas. `LICENSE` is KRT's file
  unchanged (also `LICENSES/MIT-KiCadRoutingTools.txt` at the repository root).
  The crate is `publish = false`.
- **Files vendored:** `src/types.rs` and `src/dubins.rs` byte-identical;
  `src/obstacle_map.rs`, `src/router.rs` and `src/pose_router.rs` with the
  Python binding removed (pyo3 attributes; numpy batch parameters became
  slices of fixed-size rows such as `&[[i32; 3]]`; `route_multi`'s stats dict
  became `SearchStats`; `TrackMarginArg` lost its `FromPyObject` derive).
  `src/lib.rs` is new (module list and re-exports only).
- **Not vendored:** `lane_search.rs` (KRT's `awx/` planner only),
  `identify_blocking_obstacles`, the `#[pymodule]` and the mimalloc global
  allocator (a library must not choose the binary's allocator).
- **Dependency:** `rustc-hash` 2.1 (FxHash, seedless, so no hash order varies
  between runs).
- **The record of changes:** `VENDORED.diff`, regenerated by
  `tools/krt/vendor-diff.sh` (`--check` fails when it is stale).
- **Formatting and lints:** the vendored modules carry `#[rustfmt::skip]`, and
  `src/lib.rs` names the clippy lints they trip; no KRT line was edited for
  either.
- **Tests:** `tests/serpentine.rs` reproduces KRT's own Python module on the
  serpentine maze of `rust_router/microbench.py` (path, iteration count,
  blocked frontier); the expected values come from
  `tools/krt/serpentine_reference.py`.

Users: the grid-router stages of `freerouting-krt` (X04–X06).
