# Fixtures

Specctra DSN boards, plus SES and rules files, copied from upstream Freerouting
(`danbrunski/freerouting` at `fc4bd20`, `fixtures/`). Most are named after the
upstream issue that reported a problem with the board. KiCad projects and other
non-Specctra files were left out.

These are the regression set: the reference outputs from the Java version live in
`fixtures/reference/` once the harness has produced them.
